# GTA San Andreas 3D · Los Santos WebGL Edition

Experiencia 3D interactiva en el navegador desarrollada con **Three.js (WebGL)**, JavaScript modular y filtro visual estilo PS2.

## Características
- Viewport 3D en tiempo real con Three.js
- Filtro cálido PS2 Sunset y viñeta de daño
- Arquitectura modular: main.js, world.js, models.js, entities.js, missions.js, udio.js
- Pantalla de título y HUD arcade

## Uso
Abrir index.html con un servidor local (por ejemplo, Live Server o 
px serve).
